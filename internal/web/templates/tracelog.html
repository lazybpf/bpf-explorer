the kernel tracing pipe (tracefs trace_pipe), like bpftool prog tracelog - where bpf_trace_printk() output lands. Most programs ship events over a ring buffer instead, so an empty view is normal. Newest line first.

reading trace_pipe drains it. A node has one global trace buffer, so every line shown here is consumed - anything else tailing the pipe on this node will not see it. The agent reads only while this page is streaming: pause, or leave, and it lets go of the pipe.
